Personal desktop integration

dms-integration

Keep a personal Dank Todo list in sync with Google Tasks.

This integration runs on the owner's Linux desktop as part of Dank Material Shell (DMS). It synchronizes task titles, dates, notes, completion status, deletions, and parent/subtask relationships between the Dank Todo widget and one selected Google Tasks list.

How it works

The owner signs in directly with Google and grants the Google Tasks permission. The desktop periodically connects to the Google Tasks API using that authorization. Google Tasks access is needed to read, create, update, and delete tasks as part of two-way synchronization.

This is a personal tool, not a hosted task service. This website only describes the integration; it does not accept Google sign-ins or collect task contents. Installing the desktop integration and obtaining authorization are separate from visiting this site.

Data and control

Task data and authorization files are kept in the owner's desktop account, and synchronized tasks are stored in the owner's Google account. The owner can stop synchronization or revoke Google's authorization at any time. See the privacy policy for storage, backups, and removal details.
