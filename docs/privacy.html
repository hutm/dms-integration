Privacy policy

Effective October 19, 2026. This policy describes the personal desktop integration maintained by Maksim Khadkevich.

Google data accessed

The integration requests https://www.googleapis.com/auth/tasks to select a task list and read, create, update, and delete its tasks. The API returns task-list and task records, including titles, completion state, identifiers, timestamps, notes, and other available task metadata. Synchronization uses task titles, completion state, deletion state, identifiers, and parent/subtask relationships. Internal mapping, conflict, and creation-recovery metadata is stored in private local files rather than task titles or Google notes. Exact technical note markers left by older versions are removed while retaining other user notes. It does not request Gmail, Google Drive, contacts, or calendar access.

Purpose and sharing

Google data is used only to synchronize the owner's Dank Todo widget with the selected Google Tasks list and preserve synchronization state. The desktop communicates with Google's OAuth and Tasks services over HTTPS. The integration has no hosted application backend and does not sell task data, use it for advertising, or use it to train AI models.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

Tasks are stored by Dank Todo in the owner's desktop account and by Google Tasks in the owner's Google account. OAuth credentials and synchronization metadata are stored in private files in the owner's desktop account. Local synchronization backups may contain task data. The owner may also back up local files using separately configured backup tools; those copies follow the owner's backup retention settings.

Credentials and task contents are not published on this website or in its public repository. Local data remains until the owner removes it, and Google account data remains subject to Google's controls and retention practices.

Stopping access and deleting data

The owner can stop the desktop synchronization timer and revoke access through Google Account connections. Revoking access prevents subsequent authorized API access; it does not delete existing tasks or local copies. To remove stored data, the owner must also delete the local integration credentials, synchronization state, Dank Todo data, any backups, and any unwanted Google Tasks separately. Two-way sync propagates intentional task deletions while it is enabled.

This informational website

This website has no analytics scripts, advertising, sign-in form, or task database. GitHub Pages hosts it and may collect technical request data, such as visitors' IP addresses, under the GitHub Privacy Statement.

Contact and changes

Questions can be raised in the project issue tracker. Do not include task contents, tokens, or other private information. This page will be updated if the integration's data practices change.
